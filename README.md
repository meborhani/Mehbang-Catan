# Mehbang Game

مجموعه بازی‌های آنلاین: سیطره کتان (۲ تا ۶ نفره، چند تم)، شطرنج، منچ (۲ تا ۴ نفره)، دوز و چهار در ردیف؛ با هوش مصنوعی یا اتاق آنلاین، دوستان و رده‌بندی.

## بازی با دوستان
1. یک نفر «ساخت اتاق» را می‌زند و کد ۵ حرفی را به بقیه می‌دهد.
2. بقیه کد را در «کد اتاق» می‌نویسند و «ورود» را می‌زنند.
3. میزبان تعداد صندلی‌ها را انتخاب و «شروع بازی» را می‌زند. صندلی‌های خالی را هوش مصنوعی پر می‌کند.

اتصال مستقیم بین مرورگرهاست (PeerJS)؛ میزبان باید تا آخر بازی صفحه را باز نگه دارد.

## نصب روی گوشی (PWA)
بعد از یک بار باز کردن با اینترنت، بازی روی گوشی ذخیره می‌شود و بازی تک‌نفره بدون اینترنت هم کار می‌کند.
- اندروید (Chrome): منو ⋮ ← «نصب برنامه» یا «افزودن به صفحهٔ اصلی» (یا از «تنظیمات» داخل بازی).
- آیفون (Safari): دکمهٔ اشتراک ← «Add to Home Screen».

بازی آنلاین و اتاق‌ها همچنان به اینترنت نیاز دارند.

## انتشار
Settings → Pages → Branch: `main` / root.
