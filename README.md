# کارخانه داتیس

بازی استراتژیک ۲ تا ۶ نفره (الهام‌گرفته از سیطره کتان) با اتاق آنلاین.

## بازی با دوستان
1. یک نفر «ساخت اتاق» را می‌زند و کد ۵ حرفی را به بقیه می‌دهد.
2. بقیه کد را در «کد اتاق» می‌نویسند و «ورود» را می‌زنند.
3. میزبان تعداد صندلی‌ها را انتخاب و «شروع بازی» را می‌زند. صندلی‌های خالی را هوش مصنوعی پر می‌کند.

اتصال مستقیم بین مرورگرهاست (PeerJS)؛ میزبان باید تا آخر بازی صفحه را باز نگه دارد.

## انتشار
Settings → Pages → Branch: `main` / root.
